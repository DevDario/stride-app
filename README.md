# Stride

A runner's community mobile app for Luanda, Angola. Built with Expo SDK 55 and Expo Router v4.

## Quick start

```bash
pnpm install
pnpm start        # expo start
pnpm android      # expo run:android
pnpm ios          # expo run:ios
pnpm web          # expo start --web
```

## Verify

```bash
pnpm lint         # ESLint
pnpm test         # Jest
pnpm format       # Prettier
```

## EAS builds

```bash
pnpm eas:build:dev    # Development client (internal)
pnpm eas:update:dev   # OTA update
```
